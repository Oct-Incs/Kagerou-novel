# 設計書 第5話「岡豊の煙」

## 1. この話の機能
国虎の打ち明け話で、**土佐の本当の構図**（長宗我部の本山攻めは一条の「公認」、一条の宿老は外ばかり見ている、兼定は籠の鳥）を読者に渡す。同時に、影久が**自分の頭で国虎の問いに正しく答える**ことで、第3話で定勝に一段上を行かれた影久の成長を見せ、国虎が阿波への道を託す理由を「海の腕」だけでなく「目」にする。影久は、定勝から受け取った銀を**自分の賭け**として張り、阿波へ出る。

## 2. 原文の診断
- lint（`--source`）：本文 2,877字、台詞比率 43%
- 弱点
  - **D3**：冒頭で出航し、国虎の話を回想で流す。核心の打ち明け話が「〜だという」の地の文の要約に溶けている。結びが「堂前影久の本当の戦いが、いま東の海の果てで幕を開けようとしていた」の総括型
  - **D6**：国虎が一方的に語り、影久は聞くだけ。国虎の問い（第4話の結び）に影久が答える場面がない
  - **語り手の偏り**：「悪政を敷き、領民を兵器に変えて本山を呑み込んだ長宗我部という怪物」「血塗られた爪」――地の文が長宗我部を断罪している（D3。人物の見方は人物に言わせる）
  - **代償がない**：阿波行きは国虎から与えられた好機として描かれ、影久は何も賭けていない
- 人物のブレ

  - 国虎が影久を「影久よ」と名で呼ぶ（canon どおり。ただし第4話では「堂前屋」。この話の途中で呼び方が変わる瞬間を作る）
- 残すべき原文の良さ
  - 一条の「公認」の仕組み（長宗我部を岡豊へ戻したのは一条、本山との因縁を一条も知る、だから禁じられない）
  - 「自らの腹の中で、長宗我部という名の毒虫が内臓を食い破るほどに肥大化しつつある」（国虎の台詞として）
  - 「薄々、気付いてはおられる。あのお方は世間が嗤うような単なる暗愚ではない。だが……いかんせん若すぎる」
  - 伊予で一条が敗れれば勢力図が一瞬で塗り替わる、という予見
  - 阿波の三好実休との海路を託す依頼と、安芸の木材・漆・干魚
  - **名台詞**：「今、兼定公に最も必要な物が何かわかるか？ 信用出来て、金に聡く、海を知る男だ」「今年中に財を作り、一条家公認の御用商人として兼定公へ拝謁を賜るまでに至ることじゃ」
  - 玄蕃「三好の威光を背負えば」と影久「呑み込むのは武力ではない、銭と情報だ」

## 3. 加えるもの

### 展開
- **第4話の座敷から、そのまま始める**（回想にしない）。影久が国虎の問いに答える。
  - 影久の答え：「東、安芸かと存じます。……そう申し上げるのが、商人の勘定にございましょう。されど、手前には、もう一つ見えております」「長宗我部の矛先は、一条の御家の、内側に向いておるかと」
  - 根拠は影久自身のもの：第1話の小六の「家老衆は外ばかり見ておる」、第3話の定勝の「一条の家中は、伊予だ豊後だと、外ばかり見ておる」、そして長宗我部が一条の旗を掲げて動いていること
  - 国虎の目が変わる。ここで初めて国虎が「堂前屋」ではなく**「影久よ」**と名で呼ぶ
- **国虎の打ち明け話を、やり取りにする**：国虎が「公認」の仕組みを明かし、影久が問い返す。その中で、
  - 影久が「中村の御所様は、噂のとおりの阿呆と……」と言いかけると、国虎が**声を荒らげて遮る**。「阿呆ではない！」。それから自分の声の大きさに気づき、低く言い直す。「……薄々、気付いてはおられる。だが、若すぎる」。一条一門としての国虎の誇りと、兼定への情（F-008 を育てる。定勝の「噂は、たいがい当たらぬ」に続く二人目の否定）
  - 伊予で一条が敗れれば、という予見は国虎の台詞として残す
- **阿波への依頼と、影久の賭け（代償）**：翌朝、国虎は三好実休への親書を書き、安芸の山の木材・漆・干魚を積んで阿波へ行けと言う。ただし、**国虎には荷の代を前もって払う銭がない**。荷は安芸の値で影久が買い取り、阿波で売る。影久は、定勝から受け取った代金のほとんどを、この荷に張ることになる
  - 左馬助が反対する（「定勝様の銀を、見も知らぬ阿波の湊に丸ごと張るおつもりで！？」）。影久は張る。「国虎殿は銭を持たぬ。だが、道を持っている。道は、銭では買えん」
- **国虎の「望み」の台詞（K-05 の補正）**：別れ際、国虎は「お主の望みが天下にあるとしても、それとも、どこぞの家にあるとしても」と言う。**影久は一度も国虎に素性を話していない**。影久が息を呑むと、国虎は自分の懐を軽く叩いて笑う。定勝の封書が入っているところだった（F-011。中身は影久に明かさない。読者はおおよそ察する）

### 裏描写
- **浜で干される塩**：翌朝、安芸の浜で、第4話で潮を吸った三俵の塩が筵に広げられ、城下の女子供が干している。国虎の「干せば使える」は痩せ我慢であると同時に、本当だった。塩を作る者が逃げた浜に、塩を干す者が戻ってきている
- **国親の影（新規 F-014）**：国虎が戸ノ本の報せを思い返して、ふと言う。「国親は、本陣から動かなんだそうな。あの戦好きが、じゃ」。理由は言わない（史実で国親は戸ノ本の直後、六月に病没する。第8〜9話で回収）
- **語り手の断罪を、人物の言葉に移す**：「毒虫」は国虎の台詞としてだけ使う。地の文は長宗我部を裁かない

### カタルシス
- 解放：**影久が国虎の問いに正しく答え、名で呼ばれる**（第3話で定勝に一段上を行かれた影久が、ここでは自分の目で国虎に届く）
- 小さな解放：浜の塩（第4話の損が、別の形で生きている）
- 始める溜め
  1. 「今年中に一条家公認の御用商人として兼定公へ拝謁」（第9〜12話へ）
  2. 定勝の銀を張った阿波の荷（第6話の三好の武者の屈辱へ。賭けの結果は第6〜7話）
  3. 国虎が知っている影久の何か（F-011）
  4. 国親の不在（F-014、第8〜9話）

## 9. 相談事項
相談ゲートの事項はなし。推奨案つきで確認したい。
1. **第4話の座敷から直結して始め、影久が国虎の問いに自分の目で正しく答える**（「一条の御家の、内側」）。国虎がそこで初めて「影久よ」と呼ぶ（推奨）／原文どおり回想で流す
2. **阿波の荷の代を影久が持つ**（定勝の銀のほとんどを張る。左馬助が反対）（推奨）／原文どおり国虎の荷を運ぶだけ
3. **国虎の「望み」の台詞**を「どこぞの家」に変え、封書で影久の素性の一端を知っていると読者に匂わせる（推奨）／原文の「主家の再興」を残す（国虎の当て推量として）
4. **国親の不在の伏線**（「あの戦好きが、本陣から動かなんだ」）を置く（推奨）
