## 1. 海（黒潮・季節風・海流）
出典：ユーザー提供資料（notes/kuroshio-route-2026-11-26.md）、ユーザー判定 2026-11-26。

| 項目 | 内容 | 確度 |
|---|---|---|
| 黒潮の向き | 土佐の沖を**西南西→東北東**へ流れる。室戸岬の沖では本流が岬をかすめ、流速が増す（白波・三角波） | 確 |
| 土佐湾東部の反流 | 安芸〜手結〜高知沖には、本流に引きずられた**反時計回りの弱い反流（北東→南西）**がある。**安芸から室戸へ向かう船には逆潮**、室戸を回って西へ戻る船には順潮 | 確 |
| 室戸の北（阿波南部） | 本流は紀伊水道を避けて東へ抜ける。分流が紀伊水道へ差し込み、瀬戸内の冷水・潮汐とぶつかって潮目が複雑。宍喰・牟岐・日和佐はリアス式の入江で、天然の風待ち・潮待ち港 | 確 |
| 季節風 | **夏（初夏〜秋口）は南西風**、**冬は北東風** | 確 |
| 夏の航海 | 南西風と黒潮の順流が重なり、**土佐→阿波（東行き）は速いが、阿波→土佐（西行き）は一年で最も難しい**。阿波からの援軍・補給は夏に来られない | 確 |
| 冬の航海 | 北東風で**阿波→土佐（西行き）が楽** | 確 |
| 室戸越え | 帆で越える所ではない。**潮待ち港（室津・甲浦）で凪を待ち、櫓で一気に漕ぎ切る** | 確 |
| 浦戸湾 | 入口が狭い（桂浜と種崎の間）。1560年の長浜の戦い以降、長宗我部の手にある。土佐湾の真ん中を押さえられ、一条（西）と安芸（東）の海は分断される | 確 |
| 沖合の直行 | 足摺〜室戸を沖合で一直線に結ぶのは、黒潮と外洋の荒波で当時の船には無理。浦伝いの寄港が前提 | 確 |

### 改稿済みの扱い
- 第6話（往路・五月末〜六月）：安芸→室戸は反流で逆潮（舵が重い）。室津で凪を待ち、櫓で岬を漕ぎ切る。岬の外では黒潮が船を北東へ押し流し、**速すぎて阿波の浦を素通りしかねない**のが危険
- 第7話：影久が千鶴丸に「行きは乗って参りました。帰りは、その川に逆らわねばなりませぬ」
- 第8話（復路・六月）：南西風と黒潮に逆らう難航。日和佐・牟岐で風を待ち、室戸を回れば反流に乗って安芸へ
- 第9話：影久が定勝に**季節循環の相互防衛**を提案する（§4）

## 4. 安芸〜阿波の航路と人（2026-11-26 ユーザー判定）
| 項目 | 決定 |
|---|---|
| 航路の成り立ち（案b） | **小舟が浦伝いに漕いで渡る古い航路は、室町時代からあった**（1445年『兵庫北関入船納帳』に奈半利・甲浦の船。要）。国虎が十年かけて**隠れて投資したのは、大きな商船が嵐でも通れる設備**（甲浦の波除けと蔵、宍喰の引き上げの丸太道、牟岐の風待ち小屋、日和佐の潮読み）。秘密は「道があること」ではなく「**大きな船を通す道に作り替えていること**」 |
| 湊の並び | 安芸の湊（安芸川の河口）→ **奈半利**（安芸氏配下。魚梁瀬の材木の積出港）→ **室津**（安芸氏配下。室戸岬直下の最大の潮待ち港）→ 室戸岬 → **甲浦**（国境の要衝）→ **宍喰**（ここから阿波・**海部氏**の浦）→ 牟岐 → 日和佐 → 橘浦 |
| 海部氏 | 阿波南部（海部・宍喰）の国人。**三好の配下**。国虎と親しく、甲浦〜宍喰の海運を連携して管理する（本作の設定）。**一条水道と後の一条水軍の成立に不可欠な人材として関わる**（ユーザー判定3。人物・時期は §6） |
| 安芸と三好 | **姻戚関係はない**（根拠なし。不採用）。**小規模な交易と、篠原長房との古い誼**（第6〜8話） |
| 安芸の経済 | **銭の道はあるが、米がない**。海の商いの利はあるが、平野が狭く、米と兵を自前で養う力が弱い。いまは長宗我部の台頭で陸の荷が詰まり、塩を作る者も逃げ、蔵が空（第4〜5話）。そのうえ国虎は利を湊の設備に埋めている（第6話） |
| 国虎の正室 | **一条兼定の姉（一条房基の娘）**。兼定は国虎の義弟（canon） |

## 6. 史実対照（A）の設計に使う知見
- **一条水道（第26話〜）**：史実の一条家に足りなかったのは「黒潮と季節風を、文化・贅沢品の道ではなく、長宗我部の横腹を突き兵站を断つための道として使う戦略眼」。本作では影久がそれを持ち込む
  1. 須崎・宇佐（浦ノ内湾）を拠点に、浦戸の出入りを監視・封鎖する（原文 第26話と一致）
  2. 豊後・大友水軍（若林鎮興ら。要）を足摺・宿毛・須崎に駐留させる。見返りは土佐の材木と、堺への直通交易の分け前
  3. 本山・津野へ、仁淀川河口や須崎経由で鉄・火薬・塩・銭を海で供給する
  4. **季節循環の相互防衛**：夏は西（一条・津野）の船が南西風と黒潮に乗って東の安芸を支え、冬は東（阿波・安芸）の船が北東風に乗って西を支える。安芸・室戸・甲浦の関の利をまとめ、同盟を約定にする
- **季節循環の相互防衛の初出**：影久が初めて黒潮を越えて阿波から土佐へ帰った後（第8話の帰路で体で知る）、**第9話で定勝に提案する**（ユーザー判定12）
- **八流（第53話）**：国虎が元親を破れたのは、**影久の働きで築かれた堅固な相互防衛**による（史実で国虎を滅ぼした「夏に援軍が来ない」弱点を、西からの支えが埋める）（ユーザー判定13）
- **海部氏**：甲浦〜宍喰の海を国虎と共に管理してきた家。三好配下でありながら、一条水道・一条水軍の成立に欠かせない人物を出す。三好との関係（長房の黙認、千鶴丸の鈴〈F-018〉）を通して一条側と結ぶ。人物（当主か一族か、名）と初登場の話は、該当話の設計書で決める（史実の海部友光は1570年代の当主。1560年の当主は要検証）
