## 書式（1話ごと）
```
## 第N話 題名（作中の年月）
- あらすじ：（3〜6文。誰が、何を賭けて、何をして、どうなったか。固有名詞・数字は原文どおり）
- 人物：（初登場の人物と、この話で分かった台帳事項。年齢の記述、一人称、他者からの呼称、官位・地位・所領の変化、婚姻・主従・敵対の変化、生死。原文の語句を「」で引く）
- 兼定：（登場するなら、表の顔か裏の顔か。誰に何を見せたか。口調の実例を一つ引く。年齢の記述があれば必ず引く）
- 影久（影教・教定）：（登場するなら、何をしたか。内面の記述。登場しないなら「登場せず」）
- ブレ：（canon の補正リスト K-xx に当たるもの、および新しく見つけた矛盾。原文の語句を引く。年齢・呼称・続柄・官位・時系列・人名表記・口調）
- 史実：（この話が扱う史実の出来事と日付。原文の記述のまま。疑わしい点には「要検証」）
- 死・弔い：（名前のある人物の死、葬送、追悼の場面があれば。兼定の鎮魂の舞・歌を置ける候補か）
- 強み：（残すべき場面・台詞・仕掛け）
- 弱点：（D番号つき。特に、計画が破れない／語り手の総括／敵が敗因を解説／要約で流した大事件）
- 改稿の種：（展開・裏描写・カタルシス・史実との対照と同期・代償の候補。具体的に）
```

## 特に拾ってほしいこと
- **人物のブレ**：年齢（兼定は天文十二年＝1543年生、数え年。影久は天文八年＝1539年生）、呼称（兼定は「御所様」が正、「公方様」は誤り）、続柄（阿喜多は兼定の妹が正）、口調（「でおじゃる」を使ってよいのは兼定だけ）
- **「再興」「奪還」**：影久の目標を「尼子再興」「出雲奪還」と書いている箇所（正しくは、自分を当主とする新しい尼子氏の立ち上げ）
- **毛利・尼子・山中鹿之助・一条内政・ジュスタ・阿喜多・長宗我部親泰**に関する記述はすべて拾う（改稿で筋を足す箇所のため）
- **飢え・兵糧攻め・経済封鎖で民が苦しむ描写**と、それに対する兼定の態度（兼定の核「人命と尊厳を尊ぶ」と衝突しないか）
- **兼定の計画が外れた場面**があれば必ず記録する（ほぼ無いはずなので、無ければ「計画どおり」と書く）
- 各話の末尾の締め方（同じ型の反復を数える）
