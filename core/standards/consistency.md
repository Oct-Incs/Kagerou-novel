# 人物整合性の基準（汎用）

人物像のブレ（年齢・口調・地位・立場・呼称・関係）は**必ず補正する**。読者の信頼を最も早く失う欠陥だからである。

---

## C1. 台帳が正、原文は参考
- 人物の事実は `bible/canon.md` を正とする。原文と台帳が食い違ったら台帳に合わせて直す
- 台帳に無い事実を新しく書いたら、Step5 で台帳に追記する
- 台帳そのものが誤っていると判断したら、本文を書く前に台帳を直し、その理由を監査記録に残す

## C2. 台帳に持たせる項目（人物ごと）
| 項目 | 内容 |
|---|---|
| 生年・年齢の数え方 | 例：天文十二年（1543）生。数え年で表記する |
| 一人称 | 公的な場／私的な場／例外条件 |
| 口調 | 語尾、敬語の水準、口癖。例文を1〜2行 |
| 他者からの呼称 | 誰が、どの時期に、何と呼ぶか（表にする） |
| 地位・官位・所領 | 話数ごとの変化 |
| 関係 | 主要人物との関係と、その変化（話数つき） |
| 外的目標／内的課題 | drama.md D8 |
| 外見の固定要素 | 変わらない特徴。年齢による変化 |
| 生死 | 没年・没話 |

## C3. 監査で必ず照合すること
1. 登場人物全員の**その話の時点での年齢**（作中年 − 生年 + 1）
2. 一人称・語尾が口調定義と合っているか（例外条件に当たるなら、その条件が場面にあるか）
3. 呼称が「誰が・いつ・誰を」の表と合っているか
4. 地位・官位がその時点のものか（昇進前の官名で呼んでいないか、昇進後に古い官名を使っていないか）
5. 関係（主従・婚姻・敵対・恩讐）がその時点のものか
6. 死んだ人物が登場・言及されるときの扱い

## C4. 補正の記録
原文から補正した点は、監査記録の「整合性補正」欄に `原文 → 改稿（根拠：canon §人物名）` の形で全件残す。
