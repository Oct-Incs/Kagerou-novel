# 書式基準：Web連載を正とし、書籍・電子書籍へ転用できる形

## W1. 原稿ファイル
- 1話1ファイル `drafts/epNNN.md`
- 先頭に YAML の前付け（id, title, 作中年月, 字数, 状態）
- 本文の最初の見出しは `# 第N話　題名` のみ。年代や舞台の見出しは本文に書かず、前付けに置く（作中では冒頭の描写で示す）

## W2. 段落と改行（Web）
- 地の文の段落は1〜3文。スマートフォンで5行を超える塊を作らない
- 台詞は独立した段落にする。台詞と、それに続く所作は同じ段落でもよい
- 場面転換は空行を挟んで `◇` を一行置く
- 段落の頭の字下げはしない（Web掲載時の慣例）。書籍化の変換時に一括で付ける

## W3. ルビと強調
- ルビは `｜親文字《るび》`（小説家になろう・カクヨム共通記法）。初出の難読語、人名の初出、読みが分かれる官職名に振る
- 傍点は `《《語》》`（カクヨム記法）。使用は1話2回まで
- Markdown の太字・斜体は本文で使わない

## W4. 前書き・後書き
- 本文ファイルには含めない。必要な場合は `drafts/epNNN.notes.md` に分けて書く（掲載時に使うかは作者が決める）

## W5. 書籍・電子書籍への転用
- 漢数字を基本とし、算用数字は年号の西暦併記など作品方針で認めたものに限る
- 「！？」等の約物は全角。感嘆符・疑問符の後には全角空白（文末の閉じ括弧の直前を除く）
- 縦書きで崩れる記号（`~`、半角英数、絵文字）を使わない
- これらの方針を守っていれば、書籍化時の変換は「字下げ付与」「ルビ記法の変換」「場面転換記号の置換」の機械処理で済む
